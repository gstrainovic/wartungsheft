## 🖨️ Comment imprimer et utiliser le carnet ?

### 📌 Consignes d'impression

1. **Format** : A4 (210 × 297 mm)
2. **Orientation** : Portrait
3. **Noir et blanc** : Suffisant, économise l'encre
4. **Recto-verso** : Pour un carnet compact
5. **Margines** : Laisser 1 cm de marge pour la reliure

**💡 Astuce** : Imprimez **2 exemplaires** – un pour le véhicule, un pour vos archives.

### 📝 Comment remplir le carnet ?

1. **Complétez la fiche d'identification** une fois, avec les données du véhicule.
2. **Notez chaque intervention** avec :
   - Date exacte
   - Kilométrage **précis** (indiqué sur le tableau de bord)
   - Opération réalisée (ex: "vidange + filtre à huile")
   - Nom et adresse du garage
   - Numéro de facture
   - Coût en CHF
3. **Conservez toutes les factures** avec le carnet
4. **Noter aussi les travaux faits vous-même** (ex: "changement balais essuie-glace")

## 🔄 Reconstituer l'historique sans carnet original

Si vous avez **perdu votre carnet**, voici comment reconstituer l'historique :

### 📋 Étapes à suivre

| Étape | Action | Où ? | Coût |
|-------|--------|------|------|
| 1 | **Vérifier le carnet numérique** | Portail constructeur, appli | Gratuit | — |
| 2 | **Demander un duplicata** | Concessionnaire | ~30 CHF | [SRF](https://www.srf.ch/emissions/kassensturz-espresso/environnement-et-trafic/carnet-d-entretien-perdu) |
| 3 | **Récupérer les factures** | Garages, ancien propriétaire | Variable | — |
| 4 | **Obtenir les rapports MFK** | Service cantonal | Gratuit/payant | — |
| 5 | **Faire un contrôle d'occasion TCS** | Centre TCS | 150–200 CHF | [TCS](https://www.tcs.ch/fr/conseils-tests/garage-entretien/contrôle-voiture-doccasion.php) |

### 📌 Conseils spécifiques à la Suisse

- **TecRMI Service Book** : Les garages suisses peuvent consulter les carnets numériques de **23 marques** via ce système. Coût : **5.50 CHF HT** par consultation ([Autotechnik](https://www.autotechnik.ch/fr/services/carnet-entretien-numerique/)).
- **MFK** : Les rapports de contrôle technique suisse (MFK) sont **valables comme preuve** de kilométrage.
- **Assurances** : La plupart acceptent les **factures + carnets reconstitués** comme preuve d'entretien.

## ❓ Questions fréquentes

### Est-ce que ce modèle est vraiment gratuit ?
**Oui** – pas d'inscription, pas d'e-mail requis, pas de filigrane. Tu télécharges, tu imprime, c'est tout.

### Puis-je utiliser ce carnet pour plusieurs véhicules ?
**Oui** – imprime une copie par véhicule. La première page identifie chaque voiture séparément.

### Est-ce que les garages suisses acceptent ce carnet ?
**Oui** – tant que les informations sont **complètes et exactes**. Beaucoup de garages suisses utilisent déjà des carnets papier en complément du numérique.

### Que faire si je change de garage ?
Mets simplement à jour le nom du garage dans le tableau. **Aucun problème** – l'important est la **continuité des entrées**.

### Puis-je remplir ce carnet à la main ?
**Oui** – le modèle est conçu pour être rempli **au stylo**. Les cases sont assez grandes pour écrire confortablement.
